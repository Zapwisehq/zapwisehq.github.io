# ZAPWISE product demo script

Setup: fresh browser profile, location allowed (or the city typed in), no bank linked, balances hidden. Phone (or 390 px) for the short version; desktop 1440 for the long one. Use https://zapwiseai.com/ → "Try the demo".

## 30-second version (Shorts / social)
1. **(0–4 s)** Home screen. VO: "Your day is spread across twenty apps. This is one screen."
2. **(4–10 s)** Tap the search bar, type "plan my day" → ZAP AI answer labeled *Recommendation*. VO: "Search and the assistant are the same bar."
3. **(10–16 s)** Tap the Navigate card → live traffic. Type "take me home" → Maps opens. VO: "It hands off and says *Opened*, never pretends it's done."
4. **(16–22 s)** Focus 25 → Start. VO: "Focus in one tap."
5. **(22–27 s)** Menu → ZAP Connect. VO: "You see everything it can read, and switch any of it off."
6. **(27–30 s)** End card: "ZAPWISE//OS. Free live demo at zapwiseai.com."

## 3-minute version (site / investors / testers)
1. **Company site (20 s):** homepage hero → "Six systems, one experience" → status chips (Available now / In beta / Future vision). Point out that the screenshots are real v4.26.
2. **ZAP HOME (25 s):** open `/os/`. One column on a phone, three on desktop, cards with nothing to show stay hidden. Today card weather, Now Playing opens your music app.
3. **ZAP SEARCH + ZAP AI (35 s):** type "spotify" (app result), "coffee near me" (map), "what's 72 f in c" (on-device answer), then "Ask ZAP AI: write a two-line out-of-office". Show the reply label.
4. **ZAP ACTIONS (25 s):** swipe right or press `Q` → Quick Actions. Run "Get me ready for work". Add a reminder and show the confirm step.
5. **ZAP LIFE (30 s):** Apps → Shop: add headphones with a typed price, compare, "Open store search". Say: no invented prices. Then Menu → View → Car view (big buttons, shopping off) and TV view.
6. **ZAP CONNECT + trust (30 s):** Menu → ZAP Connect: location, weather, traffic, online answers, each with what leaves the device. Banking: read-only Plaid in closed beta, last 4 only, eye hides balances.
7. **Close (15 s):** Get access page → Add to Home Screen. "Free today; Plus later only for things that cost money to run."

Never demo with a real bank account on screen or a real home address saved.
