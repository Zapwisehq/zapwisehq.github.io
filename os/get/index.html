IPHONE · FREE

Back Tap / Action Button

One free Shortcut that opens live ZAP//OS. No App Store purchase.

  1. Open Shortcuts → + → Add Action → Open URLs.
  2. Set URL to https://zapwiseai.com/os/?src=ios-shortcut.
  3. Name it ZAP//OS. Settings → Accessibility → Touch → Back Tap (or Action Button) → assign ZAP//OS.

Recipe also at /os/get/shortcut.txt.

New-tab extension

MV3 unpacked extension. Every new tab loads the live OS. Network-first — updates without reinstall.

  1. Download zapwise-os-newtab.zip and unzip it.
  2. Chrome → chrome://extensions (Edge: edge://extensions) → enable Developer mode.
  3. Load unpacked → select the unzipped folder.
